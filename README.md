# RMU Tools for Roll20

`RMU_Tools_Roll20_Mod_v0.3.1.js` is a Roll20 Mod for the official **Rolemaster Unified by Iron Crown Enterprises** character sheet.

It adds two things that are difficult to do cleanly while keeping the official sheet and its Charactermancer:

1. post-Charactermancer character-creation house rules; and
2. a Pathfinder-style custom buff manager.

The Mod does **not** replace the official Charactermancer. Roll20 Mods cannot run inside the Charactermancer sandbox, so the character-creation adjustments are applied to the finished character afterwards.

---

## Requirements

- A Roll20 game using the official Rolemaster Unified sheet.
- Roll20 Mod/API access for the game.
- A token representing the character you want to modify.

Most commands operate on the currently selected token. Chat buttons generated by the Mod include the character ID automatically.

---

## Installation

1. Open the Roll20 game outside the VTT.
2. Go to **Settings -> Mod Scripts**.
3. Create a new script, for example `RMUTools`.
4. Paste in `RMU_Tools_Roll20_Mod_v0.3.1.js`.
5. Save the script and verify that the Mod sandbox reports `RMUTools ... ready` without errors.
6. Enter the game, select a character token, and type:

```text
!rmu
```

# Character-creation house rules

## Very important: what to do in the official Charactermancer

When using this Mod for post-roll stat handling, the official RMU Charactermancer should be treated as if it is **not** handling the two boost choices or the two swaps.

So, in the official Charactermancer:

- choose **Do Nothing** for the first boost choice;
- choose **Do Nothing** for the second boost choice;
- do **not** perform the two stat swaps there.

Then finish character creation, and use the Mod afterwards.

This is intentional. The Mod is designed so you can see the **fourth die** first, then spend your boosts, and only then do your swaps.

## Required order with this Mod

Use this order:

1. Finish character creation in the official Charactermancer.
2. Use the Mod to roll the additional fourth die.
3. Use the Mod to spend the **two** post-roll boost choices.
4. Use the Mod to do the **two** post-roll swaps.
5. Reopen the character sheet if the visible sheet has not refreshed yet.

The Mod edits the RMU sheet's underlying stat attributes. Roll20 does not always repaint an already-open sheet immediately after a Mod changes those attributes.

---

## Recommended workflow commands

Open the stat menu:

```text
!rmu-stats
```

The menu includes a **Reset workflow** button and tracks:

- post-roll boosts remaining; and
- post-roll swaps remaining.

If you want to reset the post-roll workflow manually from the current creation stats:

```text
!rmu-stats --resetworkflow
```

This resets the Mod's counters to:

- **2 post-roll boost choices**
- **2 post-roll stat swaps**

It also locks in the current ranking of the creation stats so the **Raise to 90** and **Raise to 85** buttons behave consistently.

---

## Fourth stat die

From the stat menu click **Roll fourth die**, or use:

```text
!rmu-stats --extra
```

For every stat the Mod:

- rolls one additional d100;
- applies the power-level minimum (for example, Superior rerolls values below 11);
- compares the new roll with the existing Temporary and Potential creation rolls; and
- keeps the best two results as Potential and Temporary.

Running the fourth-die command also resets the post-roll workflow to:

- **2 boosts remaining**
- **2 swaps remaining**

That is normally the correct starting point.

## Post-roll boosts

You have **two** boost choices total.

The Mod tracks those two choices. Every time you use one of the supported boost options below, the remaining post-roll boost count is reduced.

### Raise to Average

Use one average raise:

```text
!rmu-stats --average 1
```

Or start two average raises:

```text
!rmu-stats --average 2
```

Then choose the target stat(s) from the generated menu.

The power-level averages currently used by the Mod are:

| Power level | Temporary | Potential |
|---|---:|---:|
| Average | 51 | 76 |
| Superior | 56 | 78 |
| Heroic | 61 | 81 |
| Legendary | 66 | 83 |
| Epic | 71 | 86 |

The Mod will not lower a stat that is already above the corresponding average.

### Raise highest Temporary stat to 90

Use:

```text
!rmu-stats --raise90
```

This does **not** ask you to choose a stat.

It automatically applies to the **highest-ranked creation Temporary stat** from the post-roll ranking that was locked in after the fourth die / workflow reset.

Effect:

- Temporary becomes at least **90**
- Potential increases by **10**
- Potential is at least the new Temporary value
- Potential is capped at **100**

This consumes **one** of the two post-roll boosts.

### Raise second-highest Temporary stat to 85

Use:

```text
!rmu-stats --raise85
```

This also does **not** ask you to choose a stat.

It applies automatically to the **second-highest-ranked creation Temporary stat** from the same locked post-roll ranking.

Effect:

- Temporary becomes at least **85**
- Potential increases by **10**
- Potential is at least the new Temporary value
- Potential is capped at **100**

This consumes **one** of the two post-roll boosts.

### Important note about 85/90 targeting

RMU Core Law defines these options using **Temporary** stats:

- `Raise to 90` applies to the highest Temporary stat
- `Raise to 85` applies to the second-highest Temporary stat

RMU Tools therefore ranks the stats by **Temporary**, not Potential, after the fourth die has been applied.

The Mod locks that post-fourth-die ranking for the 85/90 options, so the order in which you click the two boost buttons later does not change which stats qualify.

During testing, the official Roll20 Charactermancer sometimes appeared to select stats that also had very high Potential values. That is **not enough evidence to conclude that Charactermancer ranks by Potential**, because those same stats may also have been the highest Temporary stats in the tested roll. More testing would be needed before treating that as a Roll20 discrepancy.

### Note about the official sheet implementation

The current official RMU sheet appears to contain a buggy min/max expression for the Potential adjustment on the 85/90 options. RMU Tools uses the practical rulebook-style interpretation:

- Potential = old Potential + 10
- but at least the new Temporary value
- and no more than 100

## Post-roll stat swaps

The Mod expects swaps to happen **after all post-roll boosts are complete**.

Start them with:

```text
!rmu-stats --swaps 2
```

For each swap:

1. choose the first stat;
2. choose the second stat;
3. the Mod swaps their **creation Temporary/Potential packages**.

The swap intentionally does not move later racial modifiers, buffs, or unrelated miscellaneous bonuses. Those remain attached to their actual stats.

If you still have post-roll boosts remaining, the Mod will warn you and tell you to finish boosts first.

# Buff manager

Open it with:

```text
!rmu-buff
```

or select **Buff manager** from `!rmu`.

Buffs are stored by the Mod and can be independently enabled, disabled, and deleted.

## Adding a buff

Use the **Add buff** chat button or enter a command directly:

```text
!rmu-buff --add Bless|+10 to db, +10 to rr
```

A buff has:

- a name; and
- one or more comma/semicolon-separated effects.

Examples:

```text
Bless|+10 to db, +10 to rr
Holy Strength I|+5 to strength
Fear Ward|+30 to fear rr
Protection III|+20 to db
```

## Supported targets

### Defensive Bonus

```text
+10 to db
```

Aliases include `defensive bonus`, `defence`, and `defense`.

### All Resistance Rolls

```text
+10 to rr
```

This applies to:

- Arcane
- Channeling
- Essence
- Mentalism
- Physical
- Fear

The official RMU sheet does not automatically recalculate displayed RR values when `rr_*_misc` is changed by a Mod, so RMU Tools explicitly recalculates the RR bonuses after applying/removing these buffs.

### Individual Resistance Rolls

Examples:

```text
+20 to fear rr
+10 to channeling rr
+15 to physical rr
```

### Stat bonuses

Examples:

```text
+5 to strength
+10 to quickness
```

These write to the official sheet's normal stat miscellaneous modifier field.

### Arbitrary RMU misc attributes

For fields not yet recognized by name, an explicit attribute target can be used:

```text
+10 to attr:perception_misc
```

If the attribute name does not end in `_misc`, the Mod appends `_misc` automatically.

This is an escape hatch; test custom targets on a disposable character before relying on them in play.

## Buff commands

```text
!rmu-buff --menu
!rmu-buff --add Name|+10 to db
!rmu-buff --toggle <id>
!rmu-buff --on <id>
!rmu-buff --off <id>
!rmu-buff --del <id>
!rmu-buff --refresh
```

---

## Known limitations

- Roll20 does not always live-refresh an already-open character sheet after a Mod changes attributes. Closing and reopening the sheet may still be necessary.
- The Mod currently supports post-roll boosts of:
  - Raise to Average
  - Raise to 85
  - Raise to 90
- The Mod does **not** currently implement other possible RMU stat-generation options such as extra stat-gain rolls.
- The buff system currently focuses on DB, RR, stat bonuses, and explicit `_misc` targets.
- The Mod does not alter the official Charactermancer UI itself.
