# RMU Tools for Roll20

`RMU_Tools_Roll20_Mod_v0.4.1.js` is a Roll20 Mod for the official **Rolemaster Unified by Iron Crown Enterprises** character sheet.

It adds two things that are difficult to do cleanly while keeping the official sheet and its Charactermancer:

1. post-Charactermancer character-creation house rules; and
2. a Pathfinder-style custom buff manager.

The Mod does **not** replace the official Charactermancer. Roll20 Mods cannot run inside the Charactermancer sandbox, so the character-creation adjustments are applied to the finished character afterwards.

---

## Requirements

- A Roll20 game using the official Rolemaster Unified sheet.
- Roll20 Mod/API access for the game.
- A token representing the character you want to modify.

Most commands operate on the currently selected token. Chat buttons generated by the Mod include the character ID automatically.

---

## Installation

1. Open the Roll20 game outside the VTT.
2. Go to **Settings -> Mod Scripts**.
3. Create a new script, for example `RMUTools`.
4. Paste in `RMU_Tools_Roll20_Mod_v0.4.1.js`.
5. Save the script and verify that the Mod sandbox reports `RMUTools ... ready` without errors.
6. Enter the game, select a character token, and type:

```text
!rmu
```

# Character-creation house rules

## Very important: what to do in the official Charactermancer

The official RMU Charactermancer requires both stat-boost options to be selected before it will continue. Therefore, you cannot leave those two choices blank.

With RMU Tools v0.4.1:

- choose **any legal stat-boost option** for Option 1;
- choose **any legal stat-boost option** for Option 2;
- leave **both stat swaps as `No swap`**;
- finish character creation normally.

RMU Tools then automatically removes the mandatory Charactermancer boost effects before rolling the fourth die.

The automatic undo recognizes the current official sheet's recorded history for:

- Raise to Average
- Raise to 90
- Raise to 85
- Two Stat Gain Rolls (`Creation stat gain - ...` entries)

The original rolled Temporary and Potential values survive in the initial `Temp N, Pot N` stat-history entry, so the Mod can reconstruct the pre-boost creation values even when Charactermancer has overwritten the dedicated Potential `Creation` value.

Do **not** use the Charactermancer stat swaps for this workflow. The Mod expects the original rolled stat packages to still be attached to their original stats when it performs the automatic undo and fourth-roll step.

## Required order with this Mod

Use this order:

1. In Charactermancer, select any two mandatory boost options and leave both swaps as `No swap`.
2. Finish character creation.
3. Run the Mod's fourth-die step. It first removes the mandatory Charactermancer boost effects and restores the original creation Potentials, then rolls the fourth die.
4. Use the Mod to spend the **two normal RMU post-roll boost choices**.
5. Use the Mod to spend the campaign's **three extra Raise-to-Average boosts**.
6. Use the Mod to do the **two post-roll swaps**, last.
7. Reopen the character sheet if the visible sheet has not refreshed yet.

The Mod edits the RMU sheet's underlying stat attributes. Roll20 does not always repaint an already-open sheet immediately after a Mod changes those attributes.

## Recommended workflow commands

Open the stat menu:

```text
!rmu-stats
```

The menu includes a **Reset workflow** button and tracks:

- post-roll boosts remaining; and
- post-roll swaps remaining.

If you want to reset the post-roll workflow manually from the current creation stats:

```text
!rmu-stats --resetworkflow
```

This resets the Mod's counters to:

- **2 normal RMU post-roll boost choices**
- **3 extra house-rule Raise-to-Average boosts**
- **2 post-roll stat swaps**

It also locks in the current ranking of the creation stats so the **Raise to 90** and **Raise to 85** buttons behave consistently.

---

## Preparing / undoing the mandatory Charactermancer boosts

Normally you do not need a separate preparation step because the fourth-die command performs it automatically.

To undo the mandatory Charactermancer boosts without rolling yet:

```text
!rmu-stats --prepare
```

or:

```text
!rmu-stats --undo-cm-boosts
```

`--prepare` also resets the RMU Tools post-roll counters/ranking. `--undo-cm-boosts` only removes/restores the Charactermancer boost effects.

The undo is deliberately narrow: it removes only entries written by the official character-creation boost choices and leaves unrelated stat modifiers alone.

## Fourth stat die

From the stat menu click **Undo boosts + roll fourth die**, or use:

```text
!rmu-stats --extra
```

Before rolling, the Mod automatically restores the pre-boost Charactermancer creation values.

Then, for every stat, the Mod:

- rolls one additional d100;
- applies the power-level minimum (for example, Superior rerolls values below 11);
- compares the new roll with the existing Temporary and Potential creation rolls; and
- keeps the best two results as Potential and Temporary.

Running the fourth-die command also resets the post-roll workflow to:

- **2 normal RMU boosts remaining**
- **3 extra house-rule Raise-to-Average boosts remaining**
- **2 swaps remaining**

That is normally the correct starting point.

## Post-roll boosts

You have **two** boost choices total.

The Mod tracks those two choices. Every time you use one of the supported boost options below, the remaining post-roll boost count is reduced.

### Raise to Average

Use one average raise:

```text
!rmu-stats --average 1
```

Or start two average raises:

```text
!rmu-stats --average 2
```

Then choose the target stat(s) from the generated menu.

The power-level averages currently used by the Mod are:

| Power level | Temporary | Potential |
|---|---:|---:|
| Average | 51 | 76 |
| Superior | 56 | 78 |
| Heroic | 61 | 81 |
| Legendary | 66 | 83 |
| Epic | 71 | 86 |

The Mod will not lower a stat that is already above the corresponding average.

### Raise highest Temporary stat to 90

Use:

```text
!rmu-stats --raise90
```

This does **not** ask you to choose a stat.

It automatically applies to the **highest-ranked creation Temporary stat** from the post-roll ranking that was locked in after the fourth die / workflow reset.

Effect:

- Temporary becomes at least **90**
- Potential increases by **10**
- Potential is at least the new Temporary value
- Potential is capped at **100**

This consumes **one** of the two post-roll boosts.

### Raise second-highest Temporary stat to 85

Use:

```text
!rmu-stats --raise85
```

This also does **not** ask you to choose a stat.

It applies automatically to the **second-highest-ranked creation Temporary stat** from the same locked post-roll ranking.

Effect:

- Temporary becomes at least **85**
- Potential increases by **10**
- Potential is at least the new Temporary value
- Potential is capped at **100**

This consumes **one** of the two post-roll boosts.

### Important note about 85/90 targeting

RMU Core Law defines these options using **Temporary** stats:

- `Raise to 90` applies to the highest Temporary stat
- `Raise to 85` applies to the second-highest Temporary stat

This has now been confirmed against the official Roll20 Charactermancer in testing. In one test set:

- Strength was Temp 66 / Pot 89
- Presence was Temp 64 / Pot 79

The official Charactermancer selected:

- Strength for `Raise to 90`
- Presence for `Raise to 85`

So both the rulebook and the tested Roll20 implementation use **Temporary**, not Potential, to determine the two target stats.

RMU Tools therefore ranks the stats by **Temporary** after the fourth die has been applied.

The Mod locks that post-fourth-die ranking for the 85/90 options, so the order in which you click the two boost buttons later does not change which stats qualify.

### Findings about the official Roll20 implementation

Testing also confirmed two useful implementation details.

1. **The original rolled Temp/Pot pair is preserved.**

   The Charactermancer keeps the original creation values and adds a later absolute Temporary override for the 85/90 choice. For example:

   - Strength retained `Temp 66, Pot 89` and added a separate `Raise highest to 90` Temp entry.
   - Presence retained `Temp 64, Pot 79` and added a separate `Raise highest to 85` Temp entry.

   This means the Charactermancer boost history is identifiable and, in principle, reversible without losing the original rolled values.

2. **The Potential adjustment appears buggy in the current official sheet.**

   In the same test:

   - Strength 66/89 became 90/100
   - Presence 64/79 became 85/100

   Under the intended rule, these should be:

   - Strength 66/89 -> 90/99
   - Presence 64/79 -> 85/89

   The current Roll20 sheet therefore appears to force Potential to 100 for both the 85 and 90 options.

RMU Tools uses the rulebook-style interpretation:

- Potential = old Potential + 10
- but at least the new Temporary value
- and no more than 100

A cosmetic Roll20 issue was also observed: the stored Temp-history label for the 85 option may say `Raise highest to 85`, even though the option is correctly applied to the **second-highest Temporary** stat.

## House rule: three extra Raise-to-Average boosts

The campaign house rule adds **three extra stat boosts** on top of the two normal RMU boost choices.

Each of these three extra boosts may be used to raise **any** stat to the power-level average.

For Superior characters, that means:

- Temporary: at least **56**
- Potential: at least **78**

These are separate from the two normal RMU choices. They do not consume the normal boost counter.

Open the house-rule average menu with:

```text
!rmu-stats --houseaverage 3
```

Then choose three stats from the generated buttons.

The Mod tracks the remaining house-rule boosts independently. Individual generated choices use:

```text
!rmu-stats --houseraise <stat>
```

A house-rule average boost never lowers an existing value. For example:

- 40/70 -> 56/78
- 60/70 -> 60/78
- 60/90 -> 60/90

All normal RMU boosts **and** all three house-rule average boosts should be completed before the two stat swaps.


---

## Post-roll stat swaps

The Mod expects swaps to happen **after all post-roll boosts are complete**.

Start them with:

```text
!rmu-stats --swaps 2
```

For each swap:

1. choose the first stat;
2. choose the second stat;
3. the Mod swaps their **creation Temporary/Potential packages**.

The swap intentionally does not move later racial modifiers, buffs, or unrelated miscellaneous bonuses. Those remain attached to their actual stats.

If you still have post-roll boosts remaining, the Mod will warn you and tell you to finish boosts first.

# Buff manager

Open it with:

```text
!rmu-buff
```

or select **Buff manager** from `!rmu`.

Buffs are stored by the Mod and can be independently enabled, disabled, and deleted.

## Adding a buff

Use the **Add buff** chat button or enter a command directly:

```text
!rmu-buff --add Bless|+10 to db, +10 to rr
```

A buff has:

- a name; and
- one or more comma/semicolon-separated effects.

Examples:

```text
Bless|+10 to db, +10 to rr
Holy Strength I|+5 to strength
Fear Ward|+30 to fear rr
Protection III|+20 to db
```

## Supported targets

### Defensive Bonus

```text
+10 to db
```

Aliases include `defensive bonus`, `defence`, and `defense`.

### All Resistance Rolls

```text
+10 to rr
```

This applies to:

- Arcane
- Channeling
- Essence
- Mentalism
- Physical
- Fear

The official RMU sheet does not automatically recalculate displayed RR values when `rr_*_misc` is changed by a Mod, so RMU Tools explicitly recalculates the RR bonuses after applying/removing these buffs.

### Individual Resistance Rolls

Examples:

```text
+20 to fear rr
+10 to channeling rr
+15 to physical rr
```

### Stat bonuses

Examples:

```text
+5 to strength
+10 to quickness
```

These write to the official sheet's normal stat miscellaneous modifier field.

### Arbitrary RMU misc attributes

For fields not yet recognized by name, an explicit attribute target can be used:

```text
+10 to attr:perception_misc
```

If the attribute name does not end in `_misc`, the Mod appends `_misc` automatically.

This is an escape hatch; test custom targets on a disposable character before relying on them in play.

## Buff commands

```text
!rmu-buff --menu
!rmu-buff --add Name|+10 to db
!rmu-buff --toggle <id>
!rmu-buff --on <id>
!rmu-buff --off <id>
!rmu-buff --del <id>
!rmu-buff --refresh
```

## Known limitations

- Roll20 does not always live-refresh an already-open character sheet after a Mod changes attributes. Closing and reopening the sheet may still be necessary.
- The Mod currently supports post-roll boosts of:
  - Raise to Average
  - Raise to 85
  - Raise to 90
- The Mod does **not** currently implement other possible RMU stat-generation options such as extra stat-gain rolls.
- The buff system currently focuses on DB, RR, stat bonuses, and explicit `_misc` targets.
- The Mod does not alter the official Charactermancer UI itself.

## v0.4.1: automatic Charactermancer boost undo

The official Charactermancer requires two boost selections before character creation can continue. RMU Tools now compensates for that automatically.

The official sheet's `createStatsFinalize()` logic first stores the untouched roll as a `Temp N, Pot N` history entry and then records the mandatory boost separately. RMU Tools uses that preserved initial entry to reconstruct the pre-boost stat pair.

Recognized official Charactermancer history entries are:

- `Raise to average (Pot N)`
- `Raise highest to 90 (Pot N)`
- `Raise highest to 85 (Pot N)`
- `Creation stat gain - N A`
- `Creation stat gain - N B`

For affected stats, the Mod removes those boost-history entries and restores the `Creation` Potential from the original `Temp N, Pot N` record before applying the fourth die.

This automatic undo assumes that the two Charactermancer **stat swaps were left as `No swap`**.
